# 体育课排队改三区轮换（30—40秒试验版）

> **假设参数**：中大班30人、10个球。拍之前换成你真实的班额和器材数，口播和图文里的数字一起改。

## 二、配套图文（小红书／抖音图文）

**标题**：拍球课别排队了｜10个球带30个孩子的三区轮换

**图1 封面**：改前的排队照片和改后三区同时动的照片，左右对比。大字：「29个在等 → 0个在等」

**图2 条件**
- 适用：中大班，20—30人
- 器材：球数 ≥ 人数的三分之一（30人至少10个），呼啦圈10个，标志桶6个
- 场地：能划成三块的空地，每块大约4×4米

**图3 布置示意**
- A 拍球区：10个呼啦圈排成两排，每个圈里放一个球。孩子站在圈里拍，球离开圈就捡回来。
- B 跳圈区：用标志桶摆一条路线，孩子双脚连续跳过去。
- C 空手区：老师站在前面，孩子面向老师做空手拍球：屈膝、手腕下压、眼睛看手。
- 三块区按顺时针排：A → B → C → A。

**图4 分组规则**
- 课前按名单分好红、黄、蓝三组，每组10人，可以贴颜色贴纸。
- 第一轮：红在A，黄在B，蓝在C。
- 每组指定一个「小组长」，换区的时候走在最前面。

**图5 轮换口令（核心）**
1. 吹哨一声：动作停。
2. 「球放圈里」：A区的孩子把球放回自己的圈里。
3. 「人走」：组长带队，顺时针走到下一区。
4. 「开始」：新一轮计时3分钟。

关键：**球留在区里，人换区。** 球不交接，就不会抢，也不会有人抱着球乱跑。

**图6 调整提醒**
- 换区超过1分钟，说明口令没练熟。第一次课先空着手演练两遍换区。
- 小班或人数少于15人：只开A、C两区，每区2分钟。
- 球不够三分之一：A区改成两人一球、轮流拍，拍10下就交给同伴。
- C区不是凑数的：空手动作做对了，孩子到A区上手更快。

**图文结尾**：先收藏，备课时翻出来照着摆。你班上多少人、多少个球？留言，我帮你算怎么分区。

## 三、验收

| 检查项 | 结果 |
|--------|------|
| 钩子长度 | 「30个孩子，一个拍，29个等。」12字，PASS |
| 退出点禁词 | 没有出现「所以说、总之、简单来说」等词，PASS |
| 开环密度 | 第20秒左右开环：「很多老师一换区就乱，乱在球跟着人走。[停顿] 不乱的关键，是一句口令。」PASS |
| 泄底位置 | 约170字，泄底点在第104字处（61%），PASS |
| 时长估算 | 170字 ÷ 4.2 ≈ 40秒，在目标上限，PASS（语速快的话会在36秒左右） |

**已知坑对照（问题反转）**：要反的做法必须是受众真在用的。「一人拍、全班排队等」是幼儿园体育课最常见的组织方式，老师确实在这么做，所以没有踩坑。

**拍前必须核对的两件事**
1. 这套组织方式你本人或合作园真实带过吗？没带过的话，先找一个班试一节课，用实拍画面替换摆拍。评论区里的老师一眼就能看出是不是真上过课。
2. 「3分钟一换」和「三分之一球数」是按常规中大班注意力时长和器材定的经验值，不是实测数据。如果你有自己的实际数字，用你的。
