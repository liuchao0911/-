# 超人老师 · 知识周转仓库

知识周转率闭环系统 v3.0 的存档仓库。电脑端位置：`桌面/AI/Claude Code/`。

| 目录 | 放什么 |
|---|---|
| `raw/` | 原始素材：PDF、论文、文章、个人经历、社群问答 |
| `knowledge/` | 消化后的知识文件：YAML frontmatter + wikilinks，可直接拖入 Obsidian |
| `outputs/` | 可发布成品：口播逐字稿、知识卡片、公众号稿、分发策略 |
| `inspection/` | 复盘：发布数据、完播率、转发评论、迭代记录 |

## 同步

```bash
cd ~/Desktop/AI/"Claude Code"/仓库
git pull
```
