|---|---|---|---|---|

| 8 | 2019.8，6岁女孩 | 木质地板上没铺垫子跳绳，左脚崴伤 | 场地不安全，着装没提醒，没有因材施教，器材摆放不合理 | 上集：场地配动作；下集：跳 |

## 三、按课前、课中、动作重排的安全点

### 课前

| 安全点 | 来源 |
|---|---|
| 场地：平整、无障碍、器材安装牢固、放置合适 | [舒] 4.4.2；[手则] 徒手游戏第一条 |
| 场地要和动作匹配：跳的动作不放在硬地板上 | [李] 案例8 |
| 悬浮地板拼接不平、摔倒时伤害更大；移动篮球架底座灌水灌沙，有隐患；不要给幼儿用成人6、7号球 | [舒] 4.6.1 |
| 着装：运动鞋，女孩不穿裙子，不带危险品 | [手则]；[舒] |
| 孩子状态：课前了解身体状况，不适就告诉老师 | [手则] 第8条；[李] C23 |
| 热身：课前准备里专家权重最高的一条（0.3856） | [李] 表2.50 C26 |
| 课前安全提醒：权重0.1406，排第二 | [李] C24 |
| 教案要包含安全预案：权重0.1243 | [李] C21 |
| 每节课的安全叮咛八条：方向一致（逆时针）；不推、打、摸、抓、追；用音乐或哨子控制，音乐停人就停；跌倒时双手撑地，赶快爬起来；鞋子掉了到旁边穿；游戏方向（右去左回）；女孩不穿裙子；身体不适告诉老师 | [手则] |
| 注意天气：避免烈日，准备饮水 | [手则] 球类游戏 |

### 课中

| 安全点 | 来源 |
|---|---|
| 教师风险里风险量排第一的是**上课纪律松散**（风险量69.6，全因素第1） | [舒] 表6 |
| 其后依次是：缺乏正确的保护和帮助；情绪失控、责罚幼儿；课前检查不严格；讲解示范不到位、错误动作纠正不及时 | [舒] 4.4.1 |
| 课堂管理因素在教师二级指标里权重最高（0.315）；其中排前三的是「各教学环节未执行到位」0.3211、「未明确提出游戏规则与玩法」0.2195、「未密切关注幼儿个体及群体行为」0.1422 | [李] 表2.50 |
| 在对老师的管理这一块，师生比不合理、教师负责区域过大，权重0.6358，排第一 | [李] C61 |
| 同伴因素里，「与同伴碰撞」占0.8333 | [李] C15 |
| 孩子心理风险里权重最高的是侥幸心理：上次没按要求做也没出事（0.3879） | [李] C14 |
| 体力不支时没停止练习，是孩子生理风险的一条 | [李] C7；[舒] |
| 运动中观察面色、精神、呼吸、出汗量，有不良反应及时处理或停止 | 公开依据：《托儿所幼儿园卫生保健工作规范》 |
| 课间休息要有专人巡场 | [李] 案例7 |

### 高风险动作

| 动作 | 安全点 | 来源 |
|---|---|---|
| 翻滚 | 先热身；前滚翻特别注意颈部；避免头部着地；年纪小的要大人在旁协助 | [手则] 垫上游戏 |
| 翻滚 | 口诀：一蹲二撑三低头，向前滚动像圆球 | [李] 4.4 |
| 跳 | 跳箱落到垫子上，用下蹲的姿势缓和冲力；先练跑、跳、撑、蹲这些基本动作，再连起来 | [王] |
| 跳 | 跳箱、蹦床要有人保护，人多加助教；木地板跳绳要有垫 | [李] 案例4、6、8 |
| 拉伸／柔韧 | 充分热身，循序渐进，边练边用语言沟通，留意孩子状态 | [李] 案例5 |
| 下腰等难度动作 | 胆小的孩子紧张时动作会变形 | [李] 案例3 |
| 追跑 | 方向一致（逆时针），右去左回，不推打抓追，摔倒双手撑地 | [手则] |
| 平衡 | 次数由少到多，速度由慢到快，动作由简到繁，循序渐进 | [手则] 平衡感 |
| 球类 | 手指损伤多见：球性不熟、指导不当、争抢时硬接触 | [舒] 4.1.2 |

## 四、自有观点 [01期]

- 播客第01期的主题是「安全考核在奖励什么」：考核让老师在体育活动里更敢放手，还是更不敢。
- 自有口令：**看前面 · 隔一步 · 轻轻落**。
- 讨论单附了一张「事故分场景统计表」，按大课间、体育活动、自主游戏、生活环节记一个月。
- 和[舒]的发现呼应：幼儿园和家长出于安全考虑排斥篮球活动，这与以人为本的原则相违背；[舒]还转引《3-6岁儿童学习与发展指南》：每天户外活动不少于两小时，其中体育活动不少于1小时（论文转引，引用前核对原文）。

## 五、资料的局限

1. **[李]的权重是专家意见**，用层次分析法算出来的，代表专家认为哪里风险大，不代表事故实际发生在哪里。口播里必须说「专家打分」。
2. **[李]的样本**是怀化市3到5所体育培训机构，不全是幼儿园。
3. **[舒]只调查了篮球**，损伤类型和部位的比例不能直接套到所有体育活动上。
4. **[手则]来源是台湾的体能课程资料**，属于实践经验汇编，没有标注出处年份。
5. 手则里平衡木高度一句文字乱码（「50100公分」），没有采用。
